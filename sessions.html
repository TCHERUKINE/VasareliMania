Sessions à rejouer

RECORD et REJOUER sont opérationnels. VasareliMania permet d'enregistrer les étapes et les paramètres d'une création, puis de les retrouver en relecture normale ou en REJOUER DIRECT. Il est également possible de reprendre la création après la restitution de la session.

Qu'est-ce qu'une session ?

Une session conserve les opérations et les réglages utilisés pour construire une image dans VasareliMania. Elle sert à reproduire une création, à revoir son évolution et à reprendre un travail à partir de l'état restitué.

Les sessions sont enregistrées dans le dossier habituel :

C:\Sessions VasareliMania

Selon la création, une session peut comprendre notamment :

  • les modes Sans Motif, Avec Motif, FORMES, KEPLER ou POLYGONES ;
  • les couleurs personnalisées, les inversions, les dégradés et leurs réglages ;
  • les fonds, les textures et les incrustations ;
  • les formes choisies, les assemblages de deux, trois ou quatre formes, leurs dimensions et autres paramètres ;
  • les formes célestes et leurs réglages de phase, de couleur, d'inclinaison ou de transparence lorsque ces options sont utilisées ;
  • les étapes et paramètres enregistrés pendant la composition, y compris dans l'Atelier Formes (Colonnes = 1).

Comment enregistrer une session ?

  1. Ouvrir VasareliMania et préparer son dessin (mode, couleurs, formes, fond…).
  2. Utiliser la commande RECORD pour enregistrer la session au cours de la création.
  3. Effectuer les changements souhaités : formes, couleurs, dimensions, dégradés, textures et incrustations.
  4. Conserver le fichier de session enregistré dans C:\Sessions VasareliMania pour le rejouer ou le partager.
Une session n'est pas simplement une image exportée : elle permet à VasareliMania de retrouver les opérations et les réglages mémorisés. Pour diffuser une image fixe, utilisez aussi la fonction de sauvegarde d'image.

Comment rejouer une session ?

  1. Dans VasareliMania, utiliser REJOUER et sélectionner une session enregistrée.
  2. Choisir le type de relecture souhaité : normal ou direct.
  3. Observer la reconstruction ou retrouver directement le résultat final.
  4. À la fin de la session, poursuivre les expérimentations avec les paramètres et l'interface restaurés.

Deux façons de rejouer

ModeFonctionnementQuand l'utiliser ?
REJOUER normalRestitue la progression de la création, avec ses étapes successives.Pour revoir comment une composition a été construite.
REJOUER DIRECT (0 ms)Évite les attentes intermédiaires inutiles afin de reconstituer rapidement l'état final.Pour retrouver immédiatement une création et continuer à travailler.

La durée d'une relecture dépend de la complexité de la session et du matériel utilisé.

Pause et navigation dans les étapes

En relecture normale, il est possible de mettre la session en PAUSE pour examiner une étape. Pendant cette pause, la molette de la souris permet d'avancer ou de revenir entre les états enregistrés, sans quitter la pause.

CommandeAction
Molette pendant PAUSEPasser à l'état suivant ou précédent selon le sens de rotation.
Alt + PRevenir à l'état précédent.
Alt + SAvancer à l'état suivant.

Sessions FORMES et formes célestes

Les sessions récentes peuvent restituer les assemblages de plusieurs formes ainsi que les paramètres propres aux nouvelles formes célestes : Terre, La Lune, Mars, Jupiter, Saturne, Soleil, Comète, Nébuleuse, galaxies et autres formes spatiales.

Les commandes à la molette utilisées pendant la création — notamment les réglages de phase (P), d'inclinaison (I), de couleur (C) et, pour les formes compatibles, de transparence — font partie des réglages que le système de sessions peut restituer.

Le mode Atelier Formes — Colonnes = 1 permet de composer des scènes par placement et validation successive des formes. Les compositions enregistrées peuvent ensuite être rejouées.

Réutiliser des modèles de couleurs

Deux fonctions complémentaires permettent de conserver des jeux de couleurs indépendants :

  • Maj + RECORD : enregistrer un modèle COULEURS FOND, réutilisable avec le bouton C FOND.
  • Alt + RECORD : enregistrer un modèle COULEURS FORMES, réutilisable avec le bouton C FORMES.

Ces deux modèles peuvent être combinés pour essayer de nouvelles associations de couleurs sans repartir de zéro.

Ouvrir et partager une session

Lorsque l'association des fichiers de session avec VasareliMania est installée, un double-clic sur un fichier de session permet de lancer le logiciel et sa relecture. Sinon, ouvrez la session depuis la commande REJOUER de VasareliMania.

Vous pouvez partager vos fichiers de session avec d'autres utilisateurs. Pour les découvrir, consultez la page des exemples téléchargeables.

Pour obtenir une restitution aussi fidèle que possible, utilisez une version récente de VasareliMania. Les sessions plus anciennes restent prises en charge dans les cas prévus par le logiciel, avec des réglages par défaut pour certaines options ajoutées ultérieurement.
