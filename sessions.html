Sessions à rejouer

Qu'est-ce qu'une session ?

Une session VasareliMania permet d'enregistrer les paramètres ayant servi à créer une image.

Cette fonctionnalité est actuellement en développement et sera progressivement enrichie.

Les sessions sont enregistrées automatiquement dans le dossier :

C:\Sessions VasareliMania

Chaque session pourra être sauvegardée, retrouvée et rejouée ultérieurement afin de reproduire exactement la même création.

Les sessions enregistrent notamment :

  • le mode utilisé
  • les couleurs
  • les formes
  • les textures
  • les dégradés
  • les paramètres des curseurs
  • les options de rendu

Cette fonctionnalité est actuellement en développement et sera progressivement enrichie.

Objectifs futurs

Le système de sessions permettra à terme :

  • de sauvegarder une création complète
  • de rejouer automatiquement toutes les étapes
  • de partager des créations avec d'autres utilisateurs
  • de constituer une bibliothèque de sessions
  • de servir de base à la création de GIF animés
